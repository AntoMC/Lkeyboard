Política de Privacidad y Términos de Servicio

Última actualización: Marzo 2026

En keyboard command & tools, la privacidad y seguridad de nuestros usuarios es nuestra prioridad absoluta. Como aplicación de método de entrada (IME), entendemos la sensibilidad de la información que procesas al escribir.

1. Recopilación de Información y Servicio de Teclado (IME)

keyboard command & tools NO recopila, NO almacena y NO transmite ningún tipo de información sensible o texto ingresado por el usuario. La función de teclado opera 100% de forma local en tu dispositivo.

Garantizamos que no se registra:

  • Texto escrito (pulsaciones de teclas, contraseñas o datos bancarios).
  • Listas de contactos o contenido de mensajes.
  • Ubicación geográfica del dispositivo.

2. Uso de Permisos Requeridos

La aplicación solicita permisos específicos exclusivamente para sus funciones locales:

  • Bluetooth: Para enviar o controlar texto en otros dispositivos vinculados mediante conexión remota Bluetooth.
  • Cámara: Para escanear imágenes y realizar extracción de texto (OCR) localmente.
  • Vibración: Para proporcionar respuesta háptica configurable al pulsar teclas.
  • Micrófono y Dictado por Voz: Se solicita únicamente cuando activas la función de dictado. Los datos de audio se procesan para conversión de voz a texto utilizando las APIs de Android / Google ML Kit. El audio no se almacena en servidores externos ni se recopila de forma habitual.
  • Almacenamiento / Archivos locales: Para guardar tus configuraciones de diseño, snippets y temas personalizados en el almacenamiento de tu propio dispositivo.

3. Servicios de Terceros e Identificadores Anónimos

La aplicación integra **Google AdMob** para la visualización de anuncios. AdMob puede utilizar identificadores publicitarios anónimos del dispositivo con fines analíticos y para servir anuncios contextuales, sujeto a las Políticas de Privacidad de Google.

4. Términos y Condiciones de Uso

  • Licencia de Uso: Se concede al usuario una licencia personal, no exclusiva, intransferible y gratuita para utilizar la aplicación en sus dispositivos compatibles.
  • Propiedad Intelectual: Todos los diseños, código, logotipos y funcionalidades de keyboard command & tools son propiedad exclusiva de los desarrolladores del proyecto.
  • Limitación de Responsabilidad: La aplicación se proporciona "tal cual" (AS IS), sin garantías explícitas sobre la disponibilidad ininterrumpida de sus funciones de terceros o herramientas avanzadas.

5. Almacenamiento y Eliminación de Datos

Dado que no mantenemos bases de datos externas ni cuentas de usuario, toda la configuración de la app reside únicamente en tu dispositivo. Si desinstalas la aplicación, el sistema operativo eliminará automáticamente todos tus datos almacenados.
